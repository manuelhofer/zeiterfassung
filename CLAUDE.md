# CLAUDE.md

**Lies zuerst [CHATSTART.md](CHATSTART.md).** Dort steht alles Wesentliche:
was das Projekt ist, die Arbeitsregeln in Kurzform und die Lesekarte, welche
Datei zu welcher Aufgabe gehoert.

Diese Datei enthaelt bewusst **keine** Projektinhalte, sondern nur den Verweis –
damit dieselbe Grundlage fuer jedes Werkzeug gilt (Cursor, Copilot, Aider oder
ein beliebiger Chat) und keine zweite, driftende Fassung entsteht.

## Nur fuer Claude Code

- **Nicht pushen** ohne ausdrueckliche Ansage. Lokal committen ist in Ordnung.
- Vor jeder Aenderung das Pre-Flight-Gate aus
  [docs/arbeitsregeln.md](docs/arbeitsregeln.md) durchlaufen – vor allem den
  Duplicate-Check gegen `git log`.
- Die Datenbank der lokalen Entwicklungsumgebung enthaelt **echte
  Personendaten** aus einem Serverdump. Sie gehoert nicht ins Repository und
  nicht in Ausgaben.
- Zum Ausprobieren laeuft die App unter `http://localhost/zeiterfassung`
  (siehe [docs/lokale_entwicklungsumgebung.md](docs/lokale_entwicklungsumgebung.md)).
